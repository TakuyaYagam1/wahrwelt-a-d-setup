# Каталог правил

Карточки сгруппированы по языку и типу конфигурации. В каждой карточке есть поисковый пример, уязвимый вариант, исправление и проверка. Сигналы сканера требуют проверки достижимости и контекста.

- [Java](java.md)
- [C# и .NET](csharp.md)
- [C и C++](c-cpp.md)
- [Ruby и Rails](ruby.md)
- [Rust](rust.md)
- [SQL и базы данных](sql.md)
- [Конфигурация и границы доверия](configuration.md)

Запустите [офлайн-сканер](../scanners.md), затем сверяйте конкретный rule ID с соответствующей карточкой. Для проверки исправления используйте [рецепт патча](../scanners.md#проверка-исправления).
