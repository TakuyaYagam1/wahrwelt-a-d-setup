# wahrwelt / Farm

Веб-панель принимает флаги через API, хранит очередь в PostgreSQL и показывает статусы.
Интерфейс собран на Vue 3 и Quasar 2; API работает на Python 3.15 и Flask.

Компонент основан на [S4DFarm](https://github.com/C4T-BuT-S4D/S4DFarm), коммит
`3b8b057c95e0467c6afb3a47648e8b6befd1a815`. Исходная лицензия сохранена в [общем LICENSE](../../LICENSE).
Удалены клиент запуска командных скриптов, HTTP-прокси и старые интеграции; отправку флагов
в систему проверки выполняет только отдельный процесс `farm-submit`.

Корневой Compose публикует интерфейс на `${BIND_ADDRESS:-127.0.0.1}:${FARM_PORT:-8080}`. Внутренний адрес API для Neo:
`http://farm:5000`. Оба маршрута, `/api/get_config` и `/api/post_flags`, принимают пароль в
заголовках `Authorization` и `X-Token`.

Для запуска только фермы выполните из корня `./control farm`.
Настройки соревнования задаются в корневом `.env`. Отправка включается командой
`./control farm submit-up` после настройки адреса и протокола.
Остановка отправки: `./control farm submit-down`; всей фермы: `./control farm down`.
Готовый флаг можно поставить в очередь без Neo: `./control farm flag 'ФЛАГ'`.
Для обычной ручной отправки используется метка `Manual`; указать конкретную
команду и скрипт можно через `--team` и `--script`.
